FIRMWARE, SAFELY

BIOS guide

Understand common settings; make changes in your firmware setup.

iBIOS/UEFI is controlled by your motherboard or PC maker. This app cannot read or write those settings. Names, options, and safe values vary by model.

Memory profile · XMP / EXPO

OPTIONAL

Can let compatible memory run at its rated profile. Confirm CPU and motherboard support; stability testing may be needed.

Boot order

USE CASE

Chooses which drive or device starts first. Keep your operating-system drive available, especially during installation or recovery.

Virtualization

FEATURE

Often called SVM or Intel VT-x. Needed for some virtual machines and development tools; enabling it alone does not speed up games.

Secure Boot & TPM

SECURITY

Support Windows security features. Avoid disabling them without a specific reason; encryption recovery keys may be needed after firmware changes.

Fan curves

THERMALS

Balance cooling noise and temperatures. Change gradually and verify temperatures under load using a trusted monitor.

CPU voltage / overclock

ADVANCED RISK

Can cause overheating, instability, data loss, or hardware damage. Do not apply preset values without expert model-specific guidance.

Safer route: Find your exact PC or motherboard model, read its official manual, back up important data, and locate the vendor's instructions for entering UEFI. Do not flash firmware unless the vendor directs you to do so.
Finding your firmware setup
WINDOWS

On many Windows 11 PCs: Settings → System → Recovery → Advanced startup → Restart now → Troubleshoot → Advanced options → UEFI Firmware Settings. Some devices instead use a key such as F2, Del, Esc, or F10 during startup; check the manufacturer's manual.
